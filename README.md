# Help Web — Song Analyzer

**Live site:** [https://aadidev2010pramod-stack.github.io/help-web-song-analyzer/](https://aadidev2010pramod-stack.github.io/help-web-song-analyzer/)

A dark, modern web app that:

- **Analyzes lyrics** — word count, unique words, mood (love / heartbreak / joy / anger), repetition & likely hooks
- **Identifies songs** (Shazam-style UI) — paste lyrics or use the microphone + speech recognition to match against a curated OVO / R&B library (PARTYNEXTDOOR, Drake, Bryson Tiller, and more)

## Features

| Section | What it does |
|---------|--------------|
| **Identify** | Big Listen button + lyrics matcher |
| **Analyzer** | Paste any lyrics for instant stats & mood |
| **How it works** | Simple text-parsing pipeline |
| **Top artists** | Current rotation list |

## How to run locally

Open `index.html` in any modern browser (Chrome / Edge recommended for speech recognition).

## Enable GitHub Pages (if not live yet)

1. Go to the repo **Settings → Pages**
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Save — the site will be at  
   `https://aadidev2010pramod-stack.github.io/help-web-song-analyzer/`
